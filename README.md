# Escape Room

## Sobre o projeto

Escape Room é um projeto de desenvolvimento web que busca proporcionar uma experiência interativa de enigmas, exploração e resolução de problemas.

O jogador deverá explorar diferentes ambientes, solucionar desafios e encontrar uma saída antes que o tempo acabe.

## Objetivos

- Criar diferentes salas e ambientes
- Desenvolver enigmas e puzzles
- Implementar um sistema de contagem regressiva
- Criar diferentes níveis de dificuldade
- Desenvolver um sistema de progressão
- Disponibilizar um modo tutorial

## Tecnologias utilizadas

- **Python:** lógica e funcionamento do sistema
- **Flask:** desenvolvimento do servidor web
- **HTML:** estrutura das páginas
- **CSS:** estilização e design

## Funcionalidades planejadas

- Interface interativa
- Sistema de tempo
- Desafios com diferentes dificuldades
- Navegação entre salas
- Sistema de conclusão de fases
